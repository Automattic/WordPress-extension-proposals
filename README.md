# WordPress extension proposals

Hub for technical specs related to extending WordPress. The implementations are explored as feature plugins that may or may not be proposed for WordPress core at one point.

## Purpose

\* Put discussions and specs in one place.
\* Track revisions, discussions, decisions.

## Quick Start

1. Fork the repo.
2. Copy `templates/proposal.md` to `proposals/ASP-<next‑number>.md`.
3. Write your spec.
4. Open a pull request. 

That PR **is** the discussion, review, and acceptance thread.
